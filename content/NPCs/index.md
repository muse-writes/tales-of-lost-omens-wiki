# NPCs

Every named character gets a page here. Example:

```markdown
---
title: Vellis Marrow
tags: [npc, blacksmith]
---

Vellis Marrow runs the [[Locations/Ironbell Forge|Ironbell Forge]]...
```

**Conventions:**
- One page per NPC
- Tag with `#npc` plus a faction tag (e.g. `#guild`)
- Link every mentioned place back to its `[[Locations/...]]` page
