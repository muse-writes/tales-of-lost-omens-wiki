# Session Logs

What actually happened at the table, chronologically. Name each file by date:

```
content/Sessions/2025-10-14-the-drowned-cistern.md
```

**Conventions:**
- Begin each log with a short "Previously on..." recap
- Tag with `#session`
- Link every NPC, place, and loot item that appeared — this is what grows the
  wiki over time
- Mark player-facing recaps vs. GM notes; keep spoilers in `private/`
